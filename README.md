# КБЖУ

## Что умеет приложение

| 🍽️ Блюда | 🧾 Этикетки | 📚 Каталог | 📅 Дневник |
| --- | --- | --- | --- |
| Собирайте блюдо из продуктов и задавайте вес порции | Вставьте текст этикетки — парсер извлечёт пищевую ценность | Выбирайте продукт из локального справочника или добавляйте свой | Сохраняйте продукты и порции в дневнике |

Калорийность берётся с упаковки. Если её нет, приложение рассчитывает оценку по формуле `4 × белки + 4 × углеводы + 9 × жиры`.

Парсер понимает распространённые русские обозначения Б/Ж/У, десятичную запятую, значения в кДж и типовые варианты записи состава. Результаты можно поправить вручную.

В дневнике записи сгруппированы по дням недели и дате (`ДД.ММ.ГГГГ`). Группу можно свернуть или раскрыть; заголовки групп не показывают число записей, а карточки блюд выровнены по центру.

> **Приватность:** Android-приложение хранит данные локально в Room и не запрашивает разрешение на интернет. Фотоэтикетки пока не распознаются — текст нужно вставить или ввести вручную.

## Быстрый старт

### Требования

- Android Studio Koala или новее
- Android SDK 34
- JDK 17+

Откройте проект в Android Studio или выполните сборку в терминале:

```bash
git clone https://github.com/oblvsp/kbju-app.git
cd kbju-app
./gradlew assembleDebug
```

APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`. Gradle Wrapper вместе с JAR-файлом уже включён в репозиторий.

### Скачать готовый APK

[Скачать текущую debug-сборку](kbju-app-native-debug.apk) · пакет `ru.labelcalc` · версия `1.0` (`versionCode 1`) · Android 8.0+.

APK подписан debug-ключом и предназначен для установки и проверки. Это нативное приложение; оно устанавливается отдельно от старого HTML-контейнера `ru.local.kbju`.

Запуск модульных тестов:

```bash
./gradlew testDebugUnitTest
```

## Автономная HTML-версия

В репозитории также есть HTML-калькулятор со встроенным каталогом продуктов. Он собирается из шаблона `build_app.py` и файла `products.csv`:

```bash
python3 build_app.py
```

Результат — `calorie_app.html`; его можно открыть как отдельный файл. Для подготовки файлов обновления:

```bash
python3 make_release.py \
  --build 11 \
  --base https://example.com/kbju \
  --notes "Исправления и улучшения"
```

Файлы появятся в `dist/`: `kbju-index.html` и `update.json`.

### Публикация обновления HTML-версии в GitHub

Настройки репозитория и ветки указаны в `github.config.json`. Скрипт публикует HTML-файл и манифест в существующую ветку, сохраняя исходный код и README. Номер следующей сборки берётся из удалённого `update.json`.

```bash
# Если настроен SSH-ключ GitHub
python3 publish_github.py --notes "Описание изменений"

# Или HTTPS с токеном из переменной окружения
GITHUB_TOKEN=... python3 publish_github.py --notes "Описание изменений"

# Подготовить коммит, не отправляя его
python3 publish_github.py --no-push
```

Манифест проект читает через [GitHub Contents API](https://api.github.com/repos/oblvsp/kbju-app/contents/update.json?ref=main), а HTML-файл скачивает по SHA коммита релиза. Это не позволяет кэшу ветки подменить новую сборку предыдущей. Для публичного репозитория API имеет стандартный лимит запросов GitHub без авторизации.

**Важно:** HTML-обновление работает только внутри Android-контейнера с JavaScript-мостом `AppBridge` (`httpGet`, `saveUpdate`, `restart`). Этот мост не входит в репозиторий. Обновлятор HTML-версии не устанавливает и не обновляет APK нативного приложения.

## Устройство проекта

```text
app/                         Android-приложение на Kotlin и Jetpack Compose
  src/main/java/             Экраны, расчёты и база Room
  src/test/                  Модульные тесты Android-логики
build_app.py                 Сборка автономного HTML-калькулятора
calorie_app.html             Собранная HTML-версия
products.csv                 Каталог для HTML-сборки
make_release.py              Подготовка локального HTML-релиза
publish_github.py            Публикация HTML-обновления в GitHub
off_*.py, fill_*.py          Наполнение и обработка каталога продуктов
```
