# Калорийность блюд

Полностью офлайн Android-приложение: вставьте текст этикетки продукта — парсер распознает состав, приложение считает калории и БЖУ блюда. Разрешение `INTERNET` в манифесте отсутствует, данные не покидают устройство.

## Возможности

- список блюд; в блюде — продукты с весом и итоговые калории/БЖУ;
- добавление продукта тремя способами: разбор текста этикетки (парсер), выбор из справочника, ввод вручную;
- парсер текстов этикеток (`logic/NutritionParser`) понимает форматы: «Белки 12,5 Жиры 5,0 Углеводы 60,0», «Б/Ж/У: 10/5/60», «б 10 ж 5 у 60», табличные макеты, кДж (пересчёт в ккал /4.184), запятую и точку как десятичный разделитель, латинские двойники кириллических букв;
- автоматически пополняемый справочник продуктов (имя + БЖУ на 100 г);
- расчёт: заявленная калорийность на 100 г, а если не указана — 4·Б + 4·У + 9·Ж.

## Требования

- Android Studio (Koala или новее), Android SDK 34;
- полный JDK 17+ (проверено на Java 21): нужен `jlink` из JDK — JRE не подойдёт.

## Сборка

Локальная сборка без Android Studio (как на этой машине):

```bash
JAVA_HOME=~/tools/jdk-21.0.13+9 ./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`. Юнит-тесты: `./gradlew testDebugUnitTest`.
Если `JAVA_HOME` указывает на полный JDK глобально, префикс не нужен.

1. Откройте проект в Android Studio и синхронизируйте Gradle. Файл `gradle/wrapper/gradle-wrapper.properties` настроен на Gradle 8.9; jar-обёртки в репозитории нет — Android Studio скачает дистрибутив сама. Либо с локальным Gradle: `gradle wrapper --gradle-version 8.9`, затем `./gradlew assembleDebug`.

2. Модуль Tesseract4Android и модели OCR удалены из сборки (ради лёгкого APK); зависимость с JitPack больше не требуется.

## Структура

- `app/src/main/java/ru/labelcalc/data/Database.kt` — Room: блюда, позиции блюда, справочник продуктов;
- `app/src/main/java/ru/labelcalc/logic/CalorieMath.kt` — расчёт калорий;
- `app/src/main/java/ru/labelcalc/logic/NutritionParser.kt` — эвристический парсер текстов этикеток (наследник OCR-модуля);
- `app/src/main/java/ru/labelcalc/ui/` — Compose-экраны, навигация, тема;
- `app/src/test/` — юнит-тесты парсера и математики (`./gradlew test`).

## Ограничения

- распознавание текста по фото (OCR) отключено: на экране сканирования текст этикетки нужно вставить вручную — его разберёт `NutritionParser`;
- парсер эвристический — распознанные значения всегда можно поправить на экране продукта;
- при включённой обфускации (`isMinifyEnabled = true` в release) правила keep лежат в `app/proguard-rules.pro`.
